# BuildExe

Automated builds and releases of standalone executables.

---

## 📦 Projects in this Repository

### [cross_converter](./cross_converter)
Desktop utility (PyWebView UI + CLI) to convert raw cross-reference Excel files into two standardized output formats:
- `<filename>_type1.xlsx`
- `<filename>_type2.xlsx`

---

## 📥 How to Download the Windows Executable (.exe)

GitHub Actions automatically builds the standalone Windows executable on every commit:

1. Click on the **[Actions](../../actions)** tab at the top of the repository.
2. Select the latest **Build CrossConverter Windows Executable** run.
3. Scroll down to the **Artifacts** section at the bottom.
4. Click **`CrossConverter-Windows-exe`** to download the zip file.
5. Extract the zip and run `CrossConverter.exe` on any Windows PC!
